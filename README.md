# מיפוי האקדמיה הישראלית בתחום החלל 🛰️

דאשבורד אינטראקטיבי הממפה את כל הפעילות האקדמית הקשורה לחלל במוסדות ההשכלה הגבוהה בישראל — מעבדות, תוכניות תואר, קורסים, מרכזי מחקר ותוכניות מיוחדות. הוכן עבור משימת רקיע ומנהלת החלל.

## מה יש באתר

- **חיפוש חכם** — מבין הקשר ולא רק מילים: שגיאות כתיב ("לוינים"), מושגים קרובים ("טילים" → הנעה רקטית, "חקלאות מהחלל" → חישה מרחוק), אנגלית, מספרי קורסים, ואזורים ("מעבדות בדרום").
- **מפה גאוגרפית מדויקת** של ישראל (גבולות בפירוט גבוה מ-geoBoundaries) עם מיקומי הקמפוסים האמיתיים, ים כנרת וים המלח. זום, גרירה ולחיצה לסינון.
- **תג „מיפוי רקיע"** על כל תוכנית שאותרה במיפוי הידני של צוות רקיע.
- **סוג תואר** (ראשון / מתקדמים / דוקטורט / פתוח לכולם) על כל קורס ותוכנית, כולל סינון ייעודי.
- **קישורי קורסים** — דרישות קדם וקורסי המשך מקושרים זה לזה בתוך האתר.
- **סטטוס פעילות** — פעיל / נסגר / לבדיקה, עם הערת האימות של צוות המחקר.
- **מצב עריכה** — הוספה, עריכה ומחיקה של יחידות ישירות בדפדפן. השינויים נשמרים מקומית (localStorage) וניתנים לייצוא/ייבוא כקובץ גיבוי JSON.
- ייצוא לאקסל ול-CSV לפי הסינון הנוכחי.

## מבנה הפרויקט

```
index.html      — מבנה הדף והעיצוב
app.js          — כל הלוגיקה (חיפוש, מפה, עריכה, ייצוא)
data.js         — מאגר הנתונים (נוצר אוטומטית — לא לערוך ידנית)
map-data.js     — גאומטריית המפה ומיקומי הקמפוסים
fonts.css       — גופן Assistant מוטמע
assets/         — לוגואים
build/          — מקורות הנתונים וסקריפט הבנייה
```

## עדכון הנתונים

הנתונים נערכים ב-`build/data_source.json` ומקומפלים אל `data.js`:

```bash
python3 build/build_data.py
```

הסקריפט גם בונה את אינדקס החיפוש הסמנטי (לקסיקון מושגים דו-לשוני) ואת תגי הנושא של כל יחידה.

## פריסה ל-Vercel

הריפו מחובר ל-Vercel כאתר סטטי (אין צעד build). אם עדיין לא הוגדר פרויקט:

1. נכנסים אל [vercel.com/new](https://vercel.com/new) ומייבאים את הריפו הזה.
2. שם הפרויקט: `academicprograms` (יקבע את הדומיין `academicprograms.vercel.app`).
3. Framework Preset: **Other** · ללא פקודת Build · Output Directory: ריק (שורש).
4. Deploy — וכל push לענף הראשי יתפרסם אוטומטית.
